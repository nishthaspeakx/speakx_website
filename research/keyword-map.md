## Top decisions

1. **The /vs hub owns only the navigational "SpeakX vs …" / "SpeakX comparison" cluster.** It never uses "best … app(s) in India" in title/H1/H2. That cluster (210–8,100/mo terms) stays with the existing listicle `https://speakx.ai/blog/best-english-speaking-apps-india-speakx-vs-competitors` (HTTP 200, title "Best English Speaking Apps in India (2026): How SpeakX Compares with Duolingo, Supernova, Stimuler and Others"). Article = listicle intent; hub = head-to-head intent. Article rows link out to each /vs page; each /vs page links back to the article as "see the full roundup".
2. **Head terms are not /vs targets.** "english speaking app" (49,500), "spoken english app" (27,100), "ai english speaking app" (720–880) belong to the homepage/store listings. "ai se english kaise sikhe" (5,400) and "english bolne wala app" (1,300) need Hindi-language pages (new; the old `/blog/ai-se-english-kaise-sikhe` is 404 and must never be linked). "english conversation practice" (9,900, KD64) is used only as the modifier on the Duolingo page.
3. **Disambiguation from Speak (speak.com) is the single biggest ranking problem.** Every "SpeakX vs" query we tested is answered with Speak-vs-X content (speakshark, toolradar, lingrow, funfluen, Forbes). Each page opens with "SpeakX is not Speak" and the /vs/speakx-vs-speak page is as much a disambiguation page as a comparison.
4. **Every competitor except Duolingo/ELSA already runs its own vs/alternatives pages** (Supernova, MySivi x2, Stimuler x5, EngVarta — which already ranks an "EngVarta vs SpeakX" page). No one has published any "SpeakX vs Supernova / MySivi / Stimuler / ELSA" page: these four are open gaps.
5. **Copy rules enforced in every title/meta/H1:** no "best" as fact, no "free trial" (say "free to start", "₹2 trial"), no kids/Yellow Class, prices dated "as of 12 Oct 2026, India". All titles ≤60 chars, metas ≤155 chars (script-checked).
